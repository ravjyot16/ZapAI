**ZapAI**

ZapAI is a full-stack AI SaaS platform for content creation, image editing, and productivity.

## ✨ Features

- 🤖 AI article & blog title generation
- 🖼️ AI image generation
- ✂️ Background & object removal
- 📄 AI-powered resume review
- 👥 Community with likes & publishing
- 🔐 Clerk authentication
- 💳 Free & premium usage limits

## 🛠️ Tech Stack

**Frontend:** React, Vite, Tailwind CSS, Axios  
**Backend:** Node.js, Express.js  
**AI:** Google Gemini  
**Database:** Neon PostgreSQL  
**Auth:** Clerk  
**Storage:** Cloudinary  
**Image AI:** Clipdrop
